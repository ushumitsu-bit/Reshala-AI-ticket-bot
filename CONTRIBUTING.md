# Контрибьютинг

Спасибо за интерес к проекту. Ниже — как внести изменения.

## Правила

1. **Не коммитим напрямую в `main`.** Все изменения — через Pull Request.
2. **Чистый код.** Комментарии там, где логика неочевидна; понятные имена.
3. **Проверка перед PR.** Локально: `cd frontend && yarn build`, `cd backend && python -m pytest`.
   Если ломается обратная совместимость — явно отметьте это в описании PR.

## Процесс

1. Форкните репозиторий.
2. Создайте ветку под задачу: `git checkout -b fix/short-description`.
3. Внесите изменения.
4. Запушьте в свой форк.
5. Откройте Pull Request.

В описании PR: что сделано, зачем, что могло затронуть существующее поведение.
